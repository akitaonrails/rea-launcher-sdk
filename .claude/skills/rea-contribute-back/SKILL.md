# Contribute back

Follow `<sdk>/docs/playbooks/contribute-back.md`. Draft only; post a draft only
after the user approves that numbered draft. Never print, log, commit, or pass
on credentials (`~/.config/rea/pcgamingwiki.txt` is read by scripts at runtime).
Do not try to get around a site's bot protection.
